================================================================================
RS-Personalized AI-Driven Adaptive Stimulation (Aim 2) — Progress & Rationale
================================================================================
Phase 1: Algorithmic & control software for auricular VNS (Sparrow Link).
Last updated: March 2025

--------------------------------------------------------------------------------
1. PROJECT GOAL & CONTEXT
--------------------------------------------------------------------------------

Aim 2 develops and validates patent-protected AI that optimizes auricular VNS
parameters using multi-modal physiological data. The Phase 1 scope is an
offline-trainable, online-capable inference pipeline that:
- Ingests multi-modal physiological data (ECG/PPG from PhysioNet, MIMIC-III).
- Processes HRV via wavelet transforms and time/frequency/non-linear features.
- Runs a Hybrid Ensemble (CNN + RNN + Transformer) for classification.
- Outputs state-machine controlled trigger commands to the Sparrow Link (Phase 1
  uses MockSparrow; real hardware deferred to Live Integration).

Why this scope: Establish algorithm robustness and generalizability on large
datasets before live hardware integration; meet NFRs (e.g. AUROC ≥ 0.75,
latency < 200 ms) in a controlled environment.

--------------------------------------------------------------------------------
2. WHAT HAS BEEN DONE (Implementation Summary)
--------------------------------------------------------------------------------

Overall status: 20/30 tasks (67%). Environment, Data Ingestion (except LSL),
Preprocessing & Feature Extraction, and Hybrid AI Models are complete.
Training & Validation Engine and Live Inference & Hardware API are not yet
implemented.

--- 2.1 Environment & Infrastructure (100%) ---

- Repository setup: Git, .gitignore (excludes .edf/.csv datasets to avoid
  committing large raw data).
- requirements.txt: torch, torchaudio, mne, neurokit2, pylsl, scikit-learn,
  pandas, numpy, scipy, PyWavelets (pywt), wfdb, etc.
- Directory structure: src/data, src/features, src/models, src/hardware,
  src/training, tests/, models/artifacts/, models/checkpoints/.
- config.yaml: Single source of truth for paths, LSL rate (250 Hz), HRV
  windows (30 s, 5 min), wavelet params, artifact thresholds, watchdog limits,
  training hyperparameters, and model architecture dimensions.

Why config.yaml: Centralizing all tunables avoids magic numbers, supports
reproducibility, and keeps Sparrow/FDA limits and validation thresholds in one
place for safety and traceability (FR-4.2, NFR-2.1).

--- 2.2 Data Foundation — Ingestion (80%) ---

- src/data/download_physionet.py
  - Downloads MIT-BIH AF (afdb) and PhysioNet Normal Sinus Rhythm (nsrdb) via
    wfdb into data/raw/afdb and data/raw/nsrdb.
  - MIMIC-III: does not download (credentials/export required); checks
    configured directory (data/raw/mimic3), warns if missing/empty and skips.
  - Aligns with FR-1.2 (multi-institutional datasets for AF and controls).

- src/data/dataset_parsers.py
  - Converts WFDB, EDF, and MIMIC-III CSV/EDF into a single standard schema:
    subject_id (str), signal (1D ndarray), fs (float), label (int | None).
  - WFDB: first channel used for ECG; MIT-BIH AF labels from annotations (AF
    vs normal).
  - Ensures 1D signal (first channel if multi-channel) for consistent
    downstream processing.

- src/data/dataloaders.py
  - PhysioDataset: builds rolling windows from parsed records — 10 s for CNN,
    5 min for HRV/RNN. Only includes subjects in the provided subject_ids list
    and records with sufficient length (skips short records).
  - Returns (short_tensor, long_tensor, label) with channel-first (1, T).
  - get_dataloaders(): builds train/val/test from config and split; supports
    create_split_if_missing; uses split from models/artifacts/split.json.
  - Supports configurable waveform_sec (10 s) and long_window_sec (5 min) per
    config (FR-2.2).

- src/data/splitter.py
  - create_split(): 70/15/15 by subject_id (not by window) to prevent patient
    leakage across train/val/test (TR-1.1).
  - Persists to models/artifacts/split.json so training and dataloaders share
    the same split.
  - Uses fixed seed (42) for reproducibility.

- Deferred: src/data/lsl_streamer.py (Galea LSL receiver). Planned for Live
  Integration; buffer ≥250 Hz (FR-1.1); replay-from-file mode will allow
  testing without Galea hardware.

--- 2.3 Preprocessing & Feature Extraction (100%) ---

- src/features/wavelet_filter.py
  - CWT (PyWavelets) denoising: removes baseline wander (<0.5 Hz) and
    high-frequency noise (>45 Hz). Wavelet family and scale range from
    config.yaml (e.g. cmor, scale_range [1, 64]) — FR-2.1.
  - Choice of CWT: balances time-frequency localization for physiological
    signals and aligns with Aim 2 “wavelet transformation for signal denoising
    and adaptive filtering.”

- src/features/artifact_scrubber.py
  - should_reject_window(): rejects windows where amplitude exceeds X×MAD or
    any R–R interval deviates from local median by >Y%. X, Y in config
    (amplitude_mad_multiple: 5, rr_deviation_percent: 25) — placeholders to be
    updated per validation.
  - MAD-based amplitude: robust to outliers; R–R deviation catches ectopy and
    artifact that would distort HRV.

- src/features/peak_detector.py
  - R-peak detection via neurokit2 (e.g. nk.ecg_peaks) to obtain R–R
    intervals for HRV.

- src/features/hrv_time.py
  - Time-domain HRV: RMSSD, SDNN from R–R intervals (standard indices).

- src/features/hrv_freq.py
  - Frequency-domain HRV: LF, HF, LF/HF ratio via Welch’s method (scipy.signal).

- src/features/hrv_nonlinear.py
  - Non-linear HRV: e.g. sample entropy, DFA α1; integrated into pipeline per
    Aim 2.

- src/features/pipeline.py
  - High-level pipeline: one 5-min waveform → sequence of HRV vectors for RNN.
  - Feature order fixed: rmssd, sdnn, lf, hf, lf_hf_ratio, sampen, dfa_alpha1
    (7 features). Rejected or insufficient windows yield NaN rows; pipeline
    uses config subwindow_sec (30 s) → 10 time steps over 5 min (hrv_seq_len in
    config).
  - Orchestrates: denoise → peak detection → artifact check → time/freq/
    nonlinear HRV per subwindow.

- src/features/scaler.py
  - Z-score standardization with sklearn StandardScaler. Fit on training set
    only; persist to models/artifacts/scaler.pkl. Live inference must load this
    same scaler to avoid train/test leakage and ensure consistent feature
    scale (NFR-3.1, TR-1.1).

--- 2.4 Hybrid AI Models — PyTorch (100%) ---

- src/models/cnn.py
  - 1D-CNN (nn.Conv1d) for 10-second raw waveform. Returns 128-dim embedding
    (config: cnn_embed_dim). Role: morphology and robust feature extraction
    from raw waveform (FR-3.1; Aim 2 “≥80% cross-dataset accuracy” for CNN).

- src/models/rnn.py
  - GRU (nn.GRU) over 5-minute sequences of HRV features (10 steps × 7
    features). Returns 64-dim hidden state (config: rnn_hidden_size). Role:
    temporal pattern recognition and state evolution (FR-3.2).

- src/models/transformer.py
  - nn.TransformerEncoder over the same HRV sequence. Role: attention-based
    weighting of time steps and parameter optimization (FR-3.3; Aim 2
    “≥85% parameter optimization” for Transformer).

- src/models/ensemble.py
  - HybridEnsemble: concatenates CNN, RNN, and Transformer embeddings into a
    single FC layer → single logit for BCEWithLogitsLoss (binary classification).
  - Fused dim = cnn_embed_dim + rnn_hidden_size + transformer_d_model (e.g.
    128 + 64 + 64). Dropout (0.2) for regularization.
  - Rationale: multi-architecture fusion per Aim 2 “≥90% overall
    classification” and “integrated decision-making via multi-architecture
    fusion and real-time processing.”

- src/models/pca_reduction.py
  - PCA (sklearn) to map multi-channel (e.g. Galea 8-channel) to 1-channel
    equivalent for Sparrow. Single-channel data: pass-through. Supports
    TR-2.3 (strip 80% channels, verify ≥75% baseline accuracy) and future
    Galea→Sparrow integration.

--- 2.5 Tests ---

- tests/test_preprocessing.py: denoise length/power, HRV time vs NeuroKit2
  benchmark, HRV freq keys, pipeline output shape, scaler fit/load/transform,
  artifact reject/accept.
- tests/test_models.py: CNN/RNN/Transformer/Ensemble output shapes, ensemble
  dummy forward (e.g. batch=32 → (32, 1)), PCA passthrough and multi-channel
  reduction.
- tests/test_dataloader.py: window shapes (10 s, 5 min), no patient leakage
  across splits, load_split roundtrip.

These support Phase 1 acceptance (e.g. pytest suite, coverage for
src/features/ and later src/hardware/).

--- 2.6 Not Yet Implemented ---

- Training: src/training/train.py (BCEWithLogitsLoss, AdamW; fit scaler on
  train only; persist scaler and best checkpoint).
- Evaluation: src/training/evaluate.py (AUROC, F1, Sensitivity, Specificity;
  MIMIC-III holdout; 5-fold CV; noise injection test).
- LSL: src/data/lsl_streamer.py (and replay mode).
- Hardware & safety: src/hardware/sparrow_api.py (mockable), watchdog.py
  (max duration/intensity from config; SafetyViolationException), state_machine.py.
- Live: live_inference.py (LSL/replay → preprocess → model → state machine →
  MockSparrow via watchdog only).
- Tests: test_watchdog.py, test_state_machine.py; latency profiler (10k
  heartbeats, p99 < 200 ms); 24 h HIL test.

3. RATIONALE FOR KEY CHOICES
--------------------------------------------------------------------------------

- Split by subject_id (70/15/15): Prevents information leakage between
  train/val/test and satisfies TR-1.1 (holdout by patient). Same split file
  used by dataloaders and (when implemented) train/evaluate.

- Single config.yaml: One place for LSL rate (250 Hz), HRV windows (30 s,
  5 min), wavelet params, artifact thresholds, watchdog limits, paths, and
  model dimensions. Enables reproducibility and traceability to FR/NFR/TR.

- 10 s waveform + 5 min HRV: Short window for morphology (CNN); long window
  for temporal/autonomic state (RNN/Transformer). Matches FR-2.2 and
  config (waveform_sec, hrv_window_sec, subwindow_sec).

- Hybrid ensemble (CNN + RNN + Transformer): Aligns with Aim 2 multi-architecture
  targets (CNN cross-dataset, RNN sequence, Transformer optimization, ensemble
  fusion). Single logit keeps Phase 1 scope to binary classification (e.g. AF
  vs non-AF or stimulation trigger).

- Wavelet (CWT, cmor): Documented in Aim 2 for denoising and adaptive filtering;
  configurable family/scale for tuning without code change.

- Artifact rejection (MAD + R–R %): Simple, interpretable rules; thresholds in
  config to be updated after validation so we don’t over-reject or under-reject.

- Scaler fit on train only + persist: Prevents leakage; inference uses same
  scaling as training (NFR-3.1, generalizability).

- PCA module for multi-channel → 1 channel: Prepares for Galea (multi-channel)
  to Sparrow (single-channel) and TR-2.3 channel-stripping tests without
  changing core model API.

- LSL and hardware deferred: Phase 1 focuses on data, preprocessing, and models
  with offline datasets; LSL and Sparrow/watchdog/state machine are scheduled
  for Live Integration (Weeks 6–8) so algorithm validation is not blocked by
  hardware availability.

- MockSparrow in Phase 1: All stimulation requests will go through the
  watchdog (no direct trigger_stim from AI). Phase 1 uses a mock to log
  commands and validate the control path without physical device.
